# PPOL 6818 course extension

Installed into every PPOL 6818 codespace by the course image (`ppol6818-start`). At startup it closes the Welcome page, makes sure one R console is open below the editor, and brings Claude Code forward in the right sidebar. Its PPOL 6818 panel, in the file list, has the course commands as buttons: Course setup, Build minisite and Check setup, each run in the R console.
